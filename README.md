# Банковский счёт и модульные тесты

Класс банковского счёта с операциями пополнения, списания и перевода, покрытый
модульными тестами на платформе MSTest.

**Автор:** Щеглов Даниил Никитич, группа ИПо-31
Пермский институт (филиал) РЭУ им. Г. В. Плеханова, отделение информационных технологий и программирования

## Состав решения

| Проект | Назначение |
| --- | --- |
| `src/Scheglov.Bank` | библиотека классов: счёт, транзакция, исключение |
| `src/Scheglov.Bank.Demo` | консольная демонстрация работы |
| `tests/Scheglov.Bank.Tests` | модульные тесты (MSTest) |

## Возможности класса

- конструктор с проверкой владельца и начального баланса;
- `Credit` — пополнение счёта;
- `Debit` — списание с контролем достаточности средств;
- `CanDebit` — проверка возможности списания без изменения состояния;
- `TransferTo` — перевод между счетами;
- `Close` — закрытие счёта;
- `Transactions` — журнал операций с остатком после каждой операции;
- денежные суммы хранятся в `decimal`, что исключает погрешность округления.

## Сборка и запуск

```bash
dotnet build ScheglovBank.sln -c Release
dotnet run --project src/Scheglov.Bank.Demo -c Release
```

## Тесты

```bash
dotnet test ScheglovBank.sln -c Release
```

24 теста, все проходят. Проверяются допустимые и недопустимые суммы, граничные
значения, сохранение состояния после неудачных операций, журнал и закрытие счёта.
